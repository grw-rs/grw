Three small DSLs built on macro_rules! — no procedural macros — overload Rust's operators so an edge is just ^, >>, << — and a variable-length path is just ... Every fragment is a plain struct you can build and compose in code.

Three verbs

Build, mutate, match.

One macro for each thing you do to a graph. Each returns plain Rust — reach past the macro to from_fragment(), modify(), or compile() whenever you want.

graph!

Construction

A graph literal, the way vec! is a vector literal. Group fragments to chain edges; back-reference a node to close a cycle.

let g: Undir0 = graph![
    N(0) ^ (N(1) ^ N(2))
].unwrap();
// path 0 — 1 — 2
modify!

Transactional mutation

Add, remove, and rewire nodes and edges atomically. The change applies as one unit or not at all.

let mut g: Undir0 = Graph::default();
modify!(g, [N(1) ^ N(2)]).unwrap();
// node_count == 2, edge_count == 1
search!

Pattern matching

Compile a pattern into a query and iterate every valid mapping. Cluster patterns into get (required) and ban (forbidden).

let s = search![&g,
    get(Mono) { N(0) ^ N(1) }
].unwrap();
// iterate every matching edge

Variable-length paths

A path is just ..

Prefix a pattern node with .. and the edge becomes a variable-length path: DFS or BFS traversal, length bounds, or cost-ordered navigation with Dijkstra and A* — all yielded by lazy iterators, one path per next().

the path API, on one screen
..n(1).dfs()                                              // deepest-first trails
..n(1).bfs().len(3..10)                                   // shortest-first, 3–9 edges
..n(1).navigate(Dijkstra::counted())                      // cheapest by hop count
..n(1).navigate(Dijkstra::weighted(|ev: &EV| ev.cost))    // cheapest by edge weight
..n(1).navigate(AStar::new(|ev| ev.cost, |n| h(n))).all()  // every trail, cost-ordered
..n(1).dfs().guard(|p| !p.contains(N(2)))                 // prune paths mid-walk
..n(1).drive(|n| Some(Explore::One(0)))                   // steer expansion per depth
inside a pattern — path as an edge
// any path of ≥2 edges between the
// nodes matched as 0 and 1
get(Mono) {
    n(0) ^ ..n(1).dfs().len(2..)
}
navigated — cheapest route wins
let cfg = Config::new(())
    .navigate(Dijkstra::weighted(
        |ev: &Cost| ev.0 as f64));

let (cost, path) = g
    .path_navigate(N(0), N(3),
        follow, cfg, &constraint)
    .next()
    .unwrap();
// cost 2.0 via 0 → 1 → 3

Results stream lazily — DFS yields deepest trails first, BFS shortest first, navigation in non-decreasing cost. .one() keeps textbook Dijkstra/A* dominance for the single cheapest path; .all() enumerates every trail and lets you decide when to stop pulling.

Search, composed

Say what must hold — and what must not.

A query is a set of clusters, each with its own morphism: get clusters must be found, ban clusters reject any match they can complete. Negated nodes inline the same power into a single pattern, and paths drop in anywhere an edge can.

edge variable-length path forbidden unnamed intermediate
get + ban — no common neighbor
// edges whose endpoints do NOT
// share a common neighbor
search![&g,
    get(Mono) {
        N(0) ^ N(1)
    },
    ban(Mono) {
        n(0) ^ N(2),
        n(1) ^ n(2),
    }
].unwrap()
negated node — an inline ban
// same query, one cluster:
// the ! edge must not exist
search![&g,
    get(Mono) {
        N(0) ^ N(1),
        !N(2) ^ n(1)
    }
]
// equivalence with the ban form is
// checked by the negation-parity suite
clusters + paths — finding cycles
// bind both endpoints to the SAME
// graph node → paths become cycles
search![<(), ER>;
    get(Homo) { X(0), X(1) },
    get(Mono) {
        n(0) ^ ..n(1).dfs().len(2..)
    }
]
// Homo lets 0 and 1 collapse onto one
// node; the Mono path can't reuse it

Every cluster carries its own morphism — Homo endpoints with a Mono path, SubIso cores with relaxed context. Iterate matches sequentially with a lazy backtracking iterator, or fan the search space across threads with par_iter().

Graph model

One type, three kinds of edge.

A Graph<NV, ER> is parameterized by its node-value type and its edge relation. The relation picks which operators are legal and how many edges can sit between any two nodes.

^

edge::Undir<EV>

One undirected edge between two nodes. Slot: UND.

>>  <<

edge::Dir<EV>

Up to two directed edges — one incoming, one outgoing. Slots: SRC, TGT.

^ >> <<

edge::Anydir<EV>

All three at once — undirected plus both directions. Slots: UND, SRC, TGT.

The theory underneath

Six morphisms, one lattice.

Every get and ban you saw above names one of these. A morphism maps pattern nodes to target nodes while preserving edges; three independent axes decide how strict that mapping is, and they collapse into six named morphisms, ordered from exact to anything-goes.

injective · one-to-one surjective · covers all induced · exact neighborhood
IsoExact match — same shape, same size, same edges.
SubIsoFind this exact shape inside the target.
EpiMonoBijection, but extra edges between matched nodes are OK.
MonoEach pattern node gets a unique target; extra edges OK.
EpiMust cover all target nodes; can collapse pattern nodes.
HomoAnything goes — just preserve edges.

Going up the lattice adds constraints; going down relaxes them. The meet() of two morphisms is the most relaxed one that still satisfies both.
